# M1：发布语义词汇解析

## 目标

在精确 Published Semantic Release 上建立可验证的词汇证据契约与 exact-first 解析器，让规范名、preferred term、alias/synonym、abbreviation 都能稳定落到已发布语义对象，并让歧义进入明确澄清。

## 实现步骤

1. 新增 `packages/contracts/src/context/semantic-retrieval.ts`，定义 match kind、release/object/term ref、term role、canonical phrase、evidence hash 和排序规则。
2. 在 `packages/contracts/src/context/resolved-context-package.ts` 以当前 V2 authority snapshot/route/package schema 替换旧 schema，并同步删除旧导出、fixture 与 consumer。
3. 通过 forward-only migration 建立唯一可调用的 `_v2` authority/commit RPC，从已发布语义图投影 `published_lexicon`；暂定 `10705`，实施前重新确认编号。DDL 不搬运旧数据，并删除被替代的 runtime RPC 表面。
4. 修改 `packages/platform/src/semantic/postgres-resolved-context.ts` 只读写当前契约；不提供双读、双写、兼容 adapter 或旧版本回退，也不修改历史 `10663` migration。
5. 新增 `packages/semantic/src/context/lexical-resolver.ts`，只从 authority snapshot 的已发布对象与词汇关系构造索引。
6. 修改 `packages/semantic/src/context/context-router.ts`：规范名/指标 exact → preferred → alias/synonym → abbreviation；同级多命中返回 clarification。
7. 修改 `packages/semantic/src/context/resolver.ts`，将被选 lexical evidence 送入既有 capacity 规划并构造稳定 hash。
8. 先新增合同、PostgreSQL authority 与解析失败测试，再实现；完成 contracts、platform 和 semantic 的定向验证。

## 代码分析

TIS `DefaultGraphRAGService.java` 把精确字典作为一路检索，这是可借鉴点；但其对象、属性、共享属性和词汇分路召回后仍依赖分数合并，不能直接成为 Data Agent 权威判断。

当前 `packages/semantic/src/context/context-router.ts` 仅扫描 `object.name` 与 `aliases`，有三个不足：无法区分 preferred/synonym/abbreviation 的语义强度；reason code 缺少结构化匹配证据；未给后续图扩展提供稳定起点。被替代的 authority snapshot 也没有 term role 投影。Data Agent 已在语义图中有 glossary term 和 typed term role，因此无需新增 TIS Glossary 模型，但必须由 PostgreSQL 已发布权威显式生成当前 `published_lexicon`，不能在 Web 层猜测。

## 验收标准

- Candidate、草稿、其他 workspace/datasource/release 对象无法进入索引；
- match kind、对象 ref、term ref、canonical phrase 和 evidence hash 可验证；
- preferred/synonym/abbreviation 优先级固定，`related` 不自动等同；
- 同级多命中不静默选中，返回稳定排序的 clarification；
- 中英文、大小写、首尾空白和显式缩写场景有测试；
- 同一 snapshot/question 重复运行得到相同 route、evidence 顺序和 package hash；
- 仓库内旧 authority schema、RPC、reason mapping、fixture 与 consumer 引用归零；
- 固定评测可以对比 exact 基线，但运行时不存在旧 resolver 分支或关闭当前版本后回退的开关。

## 备注

本阶段不引入 embedding、第三方搜索服务或语言模型改写。规范化仅做可解释、可测试的字符串与显式词汇关系处理。
