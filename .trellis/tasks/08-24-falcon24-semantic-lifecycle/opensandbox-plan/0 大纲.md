# OpenSandbox Python 分析执行层唯一切换方案

## 目标与非目标

本方案只替换 Data Agent 的 Python 分析执行层：把当前一次性 `main(context)`、Base64 巨型信封和 Unix Domain Socket 私有运行时，切换为 OpenSandbox 承载的有状态 Cell 会话。PostgreSQL SQL Sandbox、Published Semantic Release、`SemanticContextPackage`、`AnalysisProgram`、确定性 Oracle、Artifact/Receipt/Fence 继续保持权威，不交给 OpenSandbox。

DeepSeek 仍能编写 Python，但默认通过受控工具编排 `python_cell` 与 `statistical_operator`。BH-FDR、Theil-Sen、Mann-Kendall、HAC、Shapley、分群留存只有一个宿主维护的确定性实现；模型不能复制、覆盖或内联这些公式。数据通过 Parquet 文件传输，分析结果必须声明表格和 PNG/SVG 图表，不再把大数据塞进 JSON/Base64。

最终不保留兼容层：旧 `SandboxProgram@2`、`main(context)`、UDS wire protocol、Python runtime daemon、fallback 和双写路径在同一切换完成后删除。若 OpenSandbox 不可用，运行明确失败并返回结构化恢复建议，不回退旧运行时。

## 唯一目标架构

```text
Published Semantic Release / SemanticContextPackage
                         |
                  AnalysisProgram authority
             SQL evidence + operator call DAG
                         |
              DeepSeek controlled tool loop
                  /                 \
       python_cell(agent context)   statistical_operator
                  |                 (operator context)
                  \                 /
             sealed Parquet / JSON manifests
                         |
           declared table + PNG/SVG outputs
                         |
      deterministic Oracle + Receipt + Artifact + Fence
```

## 阶段路线

1. M0：固定源码、镜像与能力边界，完成本机探针。
2. M1：建立 OpenSandbox runtime adapter 与唯一配置。
3. M2：引入 Cell、回放和 DeepSeek 受控工具循环。
4. M3：把六类统计算子封闭在独立 operator context。
5. M4：声明、校验并持久化表格和图表产物。
6. M5：补齐资源、安全、错误分类、取消和可观测性。
7. M6：唯一切换，删除旧 UDS/`main(context)`，完成 Falcon24 30 次验收。

## 不可越过的边界

- SQL 取数仍由 PostgreSQL SQL Sandbox 执行；Python 容器不获得数据库连接串、云凭证或宿主 Docker socket。
- Agent context 不能导入或读取算子实现；operator context 只接受版本化输入合同与 sealed 文件。
- 网络默认拒绝；运行期禁止 `pip install`。依赖只能来自固定镜像和 SBOM/attestation。
- OpenSandbox Docker M0 仅证明 API 和生命周期，不代表生产强隔离。生产组合必须通过 Kata + egress sidecar，或 gVisor + Cilium `toFQDN` 的独立安全验收。
- OpenSandbox 基础 API 没有自动提供完整只读 rootfs；只能在 Kubernetes pod/template 和挂载层明确加固后宣称该能力。

## 总体验收

- 同一 sandbox 内 Cell 状态可复用；失败 Cell 可从 sealed checkpoint 重建并只重放必要 Cell。
- `python_cell` 与 `statistical_operator` 使用不同 context，越权访问、动态安装、网络访问均被拒绝。
- 六类算子只存在一个可发布实现和一个 manifest digest；仓库扫描不存在第二套公式。
- 输入/中间结果/输出均有 SHA-256、schema、行数、producer cell/operator、上下文和数据证据血缘。
- 每道 Falcon24 题同时返回数据表与至少一个可校验图表；机器字段不四舍五入，展示层可格式化。
- 五题 × COLD/WARM × 3 次 = 30 次新鲜 DeepSeek Agent 运行全部通过，flake=0；失败可归类为 transport、resource、cell、operator、artifact 或 oracle。
- 扫描证明旧 `SandboxProgram@2`、UDS Python runtime、旧信封、fallback 与 `main(context)` 生产引用为 0。
