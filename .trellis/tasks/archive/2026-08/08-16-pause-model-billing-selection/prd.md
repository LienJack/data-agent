# 暂停模型计费并恢复选择

## Goal

暂停当前产品阶段的模型计费门禁，使已经配置服务端凭据且由管理员启动的模型可在 Q&A 模型选择器中选择。保留未来恢复计费的权威状态机，不删除价格、汇率、账单或积分数据。

## Requirements

- 使用服务端权威的运行模式表达“计费暂停”，不能只改前端文案或直接更新受保护表。
- 暂停时，已配置环境凭据的系统模型视为可运行并可绑定到 Conversation/Run；`DISABLED` 模型仍不可选择。
- 暂停时模型选择与 Conversation/Run 绑定不要求价格、汇率和积分余额；恢复强制计费后重新执行原有完整门禁。
- `.env` 仍只读且密钥不得进入 API、日志、数据库或浏览器。
- 资源目录、对话切换和 Run 绑定必须使用同一模型可用性投影，不能只让下拉框假装可选。
- 不修改无关并行文件。

## Acceptance Criteria

- [x] 本地权威状态显示计费暂停。
- [x] DeepSeek/Kimi 系统模型在 Q&A 选择器显示“可运行”且可以完成资源绑定。
- [x] 暂停时账单契约不创建积分冻结；恢复强制计费时原门禁不变。
- [x] 数据库、Platform、Web 范围测试和登录浏览器验收通过。
- [x] 提交不包含 `.env`、`tsconfig.tsbuildinfo` 或并行任务改动。

## Notes

- “暂停”是可恢复的权威运行模式，不物理删除计费能力或历史记录。
